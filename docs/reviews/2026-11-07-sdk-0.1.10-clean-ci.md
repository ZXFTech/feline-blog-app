- 新增 `auth:sdk:check-installed` 和 `auth:sdk:test-registry`，校验实际安装版本、五个公开入口、登记信息，以及真实 CLI 的 JSON/人读输出。合成输入不访问数据库或真实中心。
- 本地配置检查改为核对实际安装包，不再依赖旧 tgz。严格环境回归输出当前 SDK 版本。
- Verify 和 Staging 的 verify job 使用 frozen lockfile、显式 Prisma 生成、`test:ci` 和 SDK 环境回归。两个迁移根目录都纳入不可变历史检查。
- 新增只接受专用 CI 连接的 namespace 回放工具及拒绝错误目标的测试。工具要求 `CI=true`、`CI_SDK_REPLAY=1` 和无密码 `127.0.0.1:5432/postgres`，不加载 dotenv、平台连接或维护连接。建 fixture 前检查空库、角色、schema 和扩展。

- 根 `vercel.json` 移除旧 Cron，显式采用 `pnpm install --frozen-lockfile --ignore-scripts` 与 `pnpm build`，与上次隔离生产发布的配置一致。清理接口未删除或调用，远程 Cron 设置未操作。
- 旧 Staging 工作流的 candidate job 显式设为 `false`，阻断其远程迁移、部署、提升、恢复及关联发布链。原 `feline-blog-staging` 项目实际承载正式博客，不能继续视作隔离测试目标。验证 job 保留，Vercel 项目和 Git 集成设置未修改。
