## 可审阅变更

配置加载器把所选 Manifest、environment、公开配置、凭据和池选项固定为同一快照。目标默认同 runtime，只有 development 可显式跨环境。Pool 建立前验证 hostname/port/database/username 绑定，CA 与秘密不回退另一环境，旧本地无 TLS 标志不能关闭该 SDK 目标的 TLS。改文件后需重启。

仅挂载 SDK handlers.GET/POST，不公开原始 Better Auth handler。浏览器使用 facade 和 publicConfig，登录只接收可选 returnTo。SDK 的严格 environment 同时传入，错中心或缺声明不能降级。SDK 错误不恢复旧 JWT、密码、中心自定义会话或 POST bridge。

业务身份只读读取同一 authUserId 的 User 安全投影，使用独立业务邮箱快照和业务时间。resolver 响应取消信号。资料操作使用严格 DTO、同源 JSON、限流、安装状态锁和 User 锁，复查当前 Provider/subject/邮箱及摘要；重复完成不覆盖资料，确认邮箱不改角色。角色与资源归属继续走现有守卫。

维护状态同时保护公开文章、页面、业务 API 与 Server Action。安装状态缺失、当前中心不符、恢复收据代次或 ROOT 不符时不开放。初始化阶段的账号与资料按候选/ROOT 限制，合法原目标保留到 setup。旧静态认证 API 返回 404。

实际浏览器发现 Next 16 页面 rewrite 会把 503 变成 200，已改成不依赖 React/存储/脚本的直接 503 服务文档；普通维护账户页仍使用共享 AuthFrame。另修正表单 label 与说明文字的关联。新界面复用现有 Button/Input/Checkbox、NeuPanel 和 Content，加入安全 Album fixture。

新增启动命令 `auth:sdk:dev` 只启动 Next，不调用原数据库开发编排器，先核对完整本地配置和 TLS 文件，并在子进程启动前设置公共 CA。本轮未执行。原生产模板与先前 local 模板字节摘要核对未变；新模板使用独立目录，未复制生产凭据。
