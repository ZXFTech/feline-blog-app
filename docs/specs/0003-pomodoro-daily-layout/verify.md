# Verify: 番茄钟按日布局与历史浏览 · spec 0003

## Setup

使用一个具有多个日期记录、至少一条待同步记录和至少一条冲突记录的测试账号。覆盖无记录日期、跨月日期和跨午夜结束记录。

- [x] 缩小 `Content` 可用宽度，确认两个侧栏内容按日历与操作、历史的顺序合并到右侧。
- [x] 继续缩小宽度，确认主区、日历与操作、历史变成单列，并使用页面自然滚动。
- [x] 确认计时器能容纳时水平和垂直居中，内容过高时顶部内容与控制仍可访问。

- [x] 点击相邻月份日期，确认月份和日期同时切换。使用箭头翻月，确认所选日期不变。
- [x] 点击底部右对齐的“回到今天”，确认日期和月份都回到今天。选择今天时按钮保持显示但禁用。
