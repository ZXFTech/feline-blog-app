# 0013. Blog 目录与阅读进度修复

**Date**: 2026-10-21
**Status**: Accepted

## Summary

目录与阅读进度共同跟随当前文章正文，在桌面和窄屏使用实际发生滚动的区域。桌面保留右侧目录，窄屏在正文前显示默认收起的目录。进度只计算 Markdown 正文，短文隐藏进度条；章节链接可以复制，跳转不增加浏览器历史记录。

## Requirements

**User stories**:

1. 作为读者，我希望通过完整目录跳到正文中的章节，并知道自己读到了哪里。
2. 作为窄屏读者，我希望在正文前找到目录，选择章节后直接继续阅读。
3. 作为键盘用户，我希望目录链接、折叠和目标焦点形成连贯的阅读路径。

**Acceptance criteria**:

1. **AC-1**: 目录仅收录当前 Markdown 正文的 H1 至 H6，按文档顺序显示真实文字和层级，排除文章名称、目录标题、工具栏与相邻文章。重复、中文、格式化和跳级标题可正确定位，正文 slug（标题片段标识）与 spec 0012 兼容。
2. **AC-2**: 桌面目录位于现有右栏。窄屏目录位于文章元信息之后、Markdown 正文之前，默认收起，开关显示“本文目录”及当前章节；尚无当前章节时仅显示“本文目录”。断点沿用 Content 的 1088px 容器查询，长标题换行、深层缩进、长目录和焦点不会撑宽页面或被裁切。
3. **AC-3**: 阅读进度只覆盖 Markdown 正文，不计文章名称、作者、标签、互动栏及相邻导航。正文起点对齐可阅读区域顶部时为 0%，正文末尾到达其底部时为 100%，其间按本规格公式计算并限制在 0% 至 100%。无需纵向滚动即可容纳的正文隐藏进度条，空正文同样隐藏。
4. **AC-4**: 当前章节和进度随真实纵向阅读位置更新，支持桌面主区滚动、窄屏页面滚动、快速上下滚动，以及在两种布局间调整宽度。横向滚动代码或表格、滚动目录本身，不得直接改变正文阅读进度。
5. **AC-5**: 目录使用有真实片段地址的链接。普通激活会到达当前正文中的目标标题，以替换当前历史记录的方式更新 URL，支持复制、重新打开章节链接及浏览器前进后退；保留修饰键、新标签页和复制链接的原生行为。窄屏普通激活后自动收起目录，并将焦点移到目标标题。
6. **AC-6**: 切换文章、正文替换、返回页面和卸载时，不残留旧标题、选中项、折叠状态、监听器或待执行回调。新打开章节链接时按有效锚点定位，前进后退时按浏览器或仍存续容器的实际位置计算状态，不先展示上一篇文章的进度。桌面主区重建且未恢复位置时，从文章顶部重新计算，不要求恢复上次阅读位置。图片加载、图片失败、字体就绪、代码换行和容器尺寸变化后重新测量。
7. **AC-7**: 没有正文标题时隐藏目录，长文仍显示阅读进度。空正文、无效片段、目标消失或正文尚未就绪时不会抛出整页错误、生成空链接或意外跳到另一篇文章。
8. **AC-8**: 目录文字、边框、当前项和进度继承 light、dark、sugar、warm 的现有主题语义。当前章节同时具有字重、标记和 `aria-current="location"`；链接、开关和目标标题有可见焦点。开关正确表达展开状态，进度有“正文阅读进度”的可访问名称和数值，不逐次朗读滚动变化。减少动态效果时取消本功能平滑滚动与视觉过渡。
9. **AC-9**: 公开详情及正文保持服务端输出，阅读交互只增加必要的客户端边界。沿用现有文章查询和权限，不新增数据库结构、业务 API、运行配置、包依赖或阅读记录持久化；目录与测量不改变正文内容，也不执行原始 HTML。
10. **AC-10**: Album 提供隔离的安全阅读展示，并维护来源覆盖审计。相关 Vitest、桌面 Chrome 与手机 WebKit 的真实文章验证、四主题、键盘、减少动态效果、lint、类型检查和 build 通过；窄屏问题记录复现或排除证据，不能用组件样例替代真实文章检查。

## Decision

**Chosen option**: Option 2，按文章统一阅读状态，在现有 Blog 接入点替换旧 TOC 内部逻辑。

保留 `Content` 的共享布局，以 Blog 局部目录视图和单个阅读控制器完成两种布局。继续使用 `BlogMarkdown`、`NeuPanel`、共享链接和 Button、`ProgressBar` 及现有主题 token。无需部署新服务，由现有应用维护者随页面代码维护。（basis: `AGENTS.md`，`src/AGENTS.md`，`design.md`）

**Implementation skills**: `typescript-react-patterns` (`asyrafhussin/agent-skills`, `.agents/skills/typescript-react-patterns/`) · `tailwind-css` (`paulrberg/agent-skills`, `.agents/skills/tailwind-css/`)

## Feature design

### Confirmed choices and boundaries

用户已确认正文进度、全部六级正文标题、窄屏正文前默认收起、短文隐藏进度、无标题隐藏目录、跳章节替换历史，以及窄屏选中后收起并聚焦。前进后退沿用原生位置恢复，恢复失败时从文章顶部重算，不增加会话内位置缓存。References 仅记录项目来源，不进行网页检索。

进度保留现有全页顶部细条的位置，位于导航下缘，使用共享 ProgressBar 的 `sm` 尺寸，不附加可见百分比标签。位置取实际导航下缘，不继续依赖固定的 `top-22`。本文只调整 Blog 目录需要的局部布局，不改变 Content 其他页面的区域排序。桌面的作者编辑入口继续保留既有权限和侧栏位置。

本项没有新的业务实体、表、关系或持久化字段。现有文章模型由原查询提供；下表均为当前页面内存状态，不是数据库模式设计。

### Components and state

| Boundary | Inputs and outputs | Responsibility |
| --- | --- | --- |
| 文章阅读实例 | `articleKey = String(blog.id)`、`articleTitle = blog.title`、当前正文及文章标题元素的局部引用 | 隔离当前文章，注册和撤销测量对象；可由客户端边界包裹服务端 children，不把 Markdown 渲染迁入客户端 |
| 阅读控制器 | 正文引用、有效阅读区域、当前片段；输出标题列表、当前 ID、进度或隐藏状态、导航动作 | 单一测量与生命周期所有者，只查询本实例正文，不依赖全局 `getElementById` 查找标题 |
| TOC 桌面和窄屏视图 | 同一标题列表、当前 ID 和导航动作；窄屏另有 `expanded: boolean` | 展示、链接和折叠，不创建第二个正文监听器 |
| ProgressBar | 有限的 0 至 100 数值、隐藏状态、可访问名称 | 展示主题进度；必要的名称透传采用向后兼容扩展，其他消费者默认行为保持一致 |

标题项字段为 `id: string`、`text: string`、`level: 1 | 2 | 3 | 4 | 5 | 6` 与当前 DOM 目标引用。状态为 `unready → ready → disposed`；文章身份或正文根替换时撤销旧实例并重新注册。同一根内部的正文替换需重建标题映射，正文尺寸变化只重新测量。异步回调关联实例版本，旧版本不能提交新状态。折叠状态初始为 `false`，切换文章后恢复；普通滚动或主题变化不改展开状态。

DOM 引用、事件与 props 使用严格 TypeScript 类型，接口使用 interface，状态分支使用判别联合，不引入 `any`。目录和进度只订阅需要的状态，DOM 目标及测量缓存保存在引用中。（basis: `typescript-react-patterns`）

### Reading viewport and progress

实际滚动根从正文向上检查布局中拥有纵向滚动的祖先。桌面为 Content 主区，窄屏退到 `document.scrollingElement` 和窗口事件。依据实际 overflow、尺寸和所在滚动链判断，不以设备名称或 viewport 媒体查询替代容器查询。注册可滚动但暂时没有溢出的主区时也保留尺寸监听，以便图片加载后产生溢出。

所有几何值采用同一视口坐标系。设正文顶部为 `B0`、底部为 `B1`。可阅读区域顶部 `T` 是滚动根可视顶部与导航下缘加进度带高度中的较大值；底部 `D` 是滚动根可视底部与固定页脚上缘中的较小值。应用壳测量目标为现有 `.navbar` 与 `[role="contentinfo"]`，仅用于遮挡测量，不用于正文标题定位。只扣除与正文阅读列横向重叠且当前可见的壳元素；缺失某个壳元素时使用滚动根对应边界。窗口根边界采用当前可视视口，监听可视视口变化，不改应用缩放策略。

进度带高度来自共享 `sm` 轨道的实际尺寸。即使条隐藏，阅读区域仍预留同等高度，避免隐藏状态反过来改变短文判断。进度条使用 visibility 或固定尺寸的独立测量盒保留可测尺寸，隐藏状态不参与高度公式，也不占正文文档流。

定义 `H = B1 - B0`，`V = D - T`。测量尚无有效区域、`V <= 0`、`H <= 0` 或 `H <= V + 1px` 时隐藏进度；1px 仅用于消除布局舍入误差。其他情况使用：

```text
p = clamp((T - B0) / (H - V), 0, 1)
value = p * 100
```

进度允许反向减少。正文开始前钳制为 0，正文结束后为 100，继续滚动互动栏和相邻导航不扩大分母。图片加载、代码软换行或布局改变后以新几何值重算，不承诺保持旧百分比。

首次注册即测量，之后监听实际根的被动 scroll、窗口和可视视口变化，并用 ResizeObserver 观察正文、布局容器及遮挡元素。局部 MutationObserver 监听正文的 childList、characterData 和 `id` 属性变化，刷新标题映射，不监听控制器添加的焦点属性和样式。字体就绪和图片 load/error 触发重测。滚动与尺寸通知合并到每帧最多一次测量，只在结果变化时提交 React 状态。卸载时取消帧、断开观察器并移除全部事件。无需持续定时轮询。

### Current section and headings

只从当前正文收集 H1 至 H6 的实际 DOM 标题，使用 `textContent` 的文本，不把内联标记作为 HTML 注入目录。按文档顺序保存。标题没有有效 ID 或文本时不生成空链接；空文本目录项可排除，但不修改作者正文。

当前章节以 `T` 为阅读线，取顶部已到达 `T + 1px` 的最后一个有效标题。首个标题尚未到达阅读线时为 `null`。长文进度已到 100% 时取最后一个有效标题，保证较短末节能成为当前项。短文不使用末节覆盖规则。标题全部位于阅读区域下方时不提前选中；所有判断由同一次几何快照产生，不取决于 IntersectionObserver 回调顺序。

保留 `rehype-slug` 对正文重复标题的后缀规则。正文外文章名称现有 `id={blog.title}` 可与正文 ID 冲突，本项移除该原始 ID，通过局部文章标题引用提供旧片段兼容：片段优先匹配正文标题；不匹配正文且解码后恰好等于 `articleTitle` 时，定位文章标题。这样不改正文 slug，也不保留重复 DOM ID。缺失或无法解码的片段安全忽略，不清空地址栏。

### Layout, theme and accessibility

1. 桌面右栏内用默认密度 NeuPanel 承载目录，保留侧栏自身滚动。窄屏在主区元信息和正文之间提供同一数据的折叠目录，不将作者编辑操作一起搬入正文。仅一个目录视图可见并参与 Tab 顺序，隐藏视图没有重复的 DOM ID；状态与测量仍只有一份。
2. 普通包装使用默认 padding token，目录面板由 NeuPanel 管理内边距和内部 gap。用于正文引用注册的纯结构包装显式 `p-0`，不另加视觉表面；进度轨道同样显式零内边距。列表行采用共享链接的尺寸与焦点规则，不额外规定 44px 点击目标。
3. 目录使用 `nav aria-label="本文目录"` 与有序列表；真实 H 等级通过层级结构或等价列表层级表达。每深一级增加 compact 间距尺度的缩进，并给长标题保留可换行空间。当前项使用 `--foreground` 文字、加粗、可见侧标和 `aria-current="location"`，默认文字也是正文主题色，悬浮背景取 `--muted`，边框取 `--border`。
4. 窄屏折叠开关复用 Button，提供 `aria-expanded` 和唯一 `aria-controls`。展开内容与开关在文档中相邻。选择章节后先收起，待布局稳定再重新测量目标并滚动，最后对标题执行不额外滚动的 focus。需要时仅在目标标题加 `tabIndex={-1}`，不把每个标题加入常规 Tab 顺序。
5. 进度轨道复用共享 inset 表面和 `--muted`，填充使用 `--foreground`，四主题均从变量解析。ProgressBar 的可访问数值与视觉相同，不提供 aria live；隐藏时移出可访问树。减少动态效果覆盖此处共享进度条的宽度过渡，不能只关闭 Album 动画。（basis: `design.md`，`src/components/ui/progress-bar.tsx`，`tailwind-css`）
6. 导航普通激活在正常偏好下平滑滚动，减少动态效果下立即滚动；用户滚动可中断平滑过程。目标位置以可阅读区域顶部为准，到达滚动边界时使用可达到的最近位置并保证目标可见，为 H1 至 H6 统一提供 Blog 局部滚动偏移，替代现有仅覆盖 H1 至 H4 的固定偏移。长目录需要将当前项滚入目录自身区域时，只改变目录滚动位置，不调用会连带正文或窗口滚动的操作。

### Interface surface and value sourcing

| Surface or action | Input | Output and source | Auth and failure |
| --- | --- | --- | --- |
| `/blog/[id]` 现有服务端页面 | 现有 route id | 既有 `getBlogById` 的 `blog.id`、`blog.title`、`blog.content`；提供文章身份、旧名称片段兼容和服务端正文 | 公开读取，沿用当前错误与权限流程 |
| 注册正文 | 当前实例的正文和文章标题引用 | H1 至 H6 文档序、文本、ID 和目标来自本地 DOM；布局模式来自 Content 容器查询及实际滚动链 | 不发请求；正文未就绪则隐藏阅读辅助状态并等候注册 |
| 计算状态 | 正文、滚动根、导航、进度条和页脚几何值 | `B0`、`B1`、`T`、`D` 来自实际元素边界；当前项、隐藏状态和百分比按上文公式派生 | 不读取 Cookie 或用户信息；无有效区域时不显示伪造进度 |
| 普通目录激活 | 当前实例中存在的标题 ID | `href` 使用当前路径和查询参数加编码后的 ID；保留 path/query，调用 replaceState 时合并保留现有 history.state；目标来自本实例映射 | 仅拦截无修饰键的当前页主按钮激活；失效目标重新收集，不误跳全局同名元素 |
| 初始片段及历史恢复 | 当前 URL 的 hash、popstate 和 pageshow 恢复事件、当前滚动根实际 scrollTop | 新打开文章时按有效片段定位一次，同页 hashchange 定位当前正文目标；历史返回使用浏览器恢复的位置或仍存续容器的 scrollTop | 主区重建且原生恢复未生效时以文章顶部为起点，不读取应用保存的位置；旧文章名按上述兼容规则处理 |
| 目录展示 | 当前标题列表、当前项、折叠状态、主题变量 | 标题、当前章节摘要与展开状态来自当前实例；颜色和密度来自既有 token | 文本输出；缺失标题隐藏目录 |
| Album 展示 | 固定本地 Markdown、独立文章身份、局部滚动根与演示主题 | 真实控制器和目录视图的安全样例，不调用文章 Action | 无认证、无业务数据；演示导航限定在样例，不修改 Album 路由 |

普通滚动仅更新当前项和进度，不自动改写 URL。普通目录激活使用 History 替换接口更新片段，不能清除 Next.js 已有 history.state。修饰键或新标签页依赖原生链接。新打开的文章及显式片段变化执行片段定位，历史返回则尊重原生恢复结果，不因旧 URL 片段再次跳转。初次片段定位不能在后续图片每次加载时强制重复，把用户拉回旧标题；之后只重算状态。有效片段与标题碰撞优先级均由当前文章映射决定。

历史滚动位置由浏览器或仍存续的滚动容器拥有，应用只读取当前根的实际 scrollTop，不改变 `history.scrollRestoration`，不在内存、history.state、sessionStorage 或其他存储中保存阅读位置。桌面元素滚动根重建后可能无法恢复，允许以其初始顶部位置显示并计算 0% 进度。原生恢复若稍后发生，由 scroll、pageshow 及后续测量更新；控制器不通过主动归零或重复片段跳转覆盖恢复。此边界适用于桌面和窄屏，不承诺前进后退精确返回旧阅读位置。

### Security, performance and failure handling

页面继续匿名可读，作者编辑入口沿用现有 PermissionAccess，写操作及 JWT Cookie 流程不变。本项没有新的服务端 Action、HTTP 接口、迁移、环境变量或外部服务。标题文本作为文本渲染；片段安全编码和解码，避免把用户内容拼成 CSS 选择器。测量与目录不读取或记录令牌、文章内容和浏览历史。

正常滚动不输出日志；失败通过隐藏尚无依据的状态和重新注册恢复，不增加后台上报。缺少 ResizeObserver 时仍可通过首次测量、scroll、resize 和图片事件更新，后续验证记录能力限制。目标在交互前消失时保留可用页面、刷新目录映射，不把焦点移到不相关元素。无 JavaScript 时服务端正文和原有页面阅读仍可用。

## Consequences

**Positive**:

1. 两种布局的目录、进度和导航共享可验证的正文边界，切换文章时有明确的状态归属。
2. 窄屏读者无需先滚到文末才能找到目录，键盘导航可以在目标章节继续。

**Negative / tradeoffs**:

1. 测量必须处理应用壳遮挡、动态高度及滚动根变化，增加局部观察器和浏览器回归成本。
2. 图片或代码换行改变正文高度时，百分比可能调整；它表达当前位置，不是已经阅读字数或持久完成记录。
3. 深层标题可能形成长目录，需要维护换行、缩进和目录自身滚动，不能用截断标题规避。
4. 前进后退是否回到原阅读位置取决于原生恢复能力，桌面滚动容器重建时可能从文章顶部开始。

**Neutral**:

1. 无数据迁移和新服务，组件、局部样式和详情接入可一起回退；回退时保留 scope 28 已完成的正文成果。
2. 本规格已于 2026-10-21 完成构建、真实页面验收与测试，并经用户确认接受。
